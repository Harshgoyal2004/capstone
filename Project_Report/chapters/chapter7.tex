\subsection{ECGNet — Cardiac Arrhythmia Classification}
% ──────────────────────────────────────────────────────────────────────

ECGNet was trained for 25 epochs on beats extracted from the MIT-BIH Arrhythmia Database (PhysioNet). The preprocessing pipeline applied a 4th-order Butterworth bandpass filter (0.5--40 Hz), detected R-peaks using \texttt{scipy.signal.find\_peaks} with a minimum distance of 180 samples (0.5 s at 360 Hz) and an adaptive height threshold of $\mu + 0.5\sigma$, and extracted 252-sample windows centred on each R-peak (108 pre-R + 144 post-R). The dataset yielded 109,446 annotated beats mapped to 5 \ac{aami} classes.

Training used AdamW (weight\_decay $= 10^{-4}$), Focal Loss ($\gamma = 2$), and WeightedRandomSampler to counter the 72.6\% Normal (N) class dominance. The training accuracy converged to \textbf{98.55\%} within 15 epochs, while the test accuracy stabilised at \textbf{60.0\%}, revealing a significant overfitting gap attributable to the small number of unique patients (28 train / 19 test records) and the patient-specific nature of arrhythmia morphology.

\textbf{Risk Stratification (deployed thresholds):}
The abnormality probability is computed as $1 - P(\text{Normal})$, i.e., one minus the probability assigned to the N class by the softmax output, averaged across all detected beats in the uploaded ECG. The thresholds are:
\begin{itemize}
  \item \textbf{Low}: Abnormality probability $< 0.35$
  \item \textbf{Moderate}: Abnormality probability $0.35$--$0.70$
  \item \textbf{High}: Abnormality probability $\geq 0.70$
\end{itemize}

\textbf{Discussion:} The clinically most important class — Ventricular ectopic (V, F1 = 0.77, Recall = 0.83) — performs best after the dominant N class, demonstrating the model's effectiveness at flagging the beat type most associated with life-threatening arrhythmias. The poor performance on S-class (F1 = 0.06) and F-class (F1 = 0.04) is a known and documented limitation: these classes represent 1.6\% and 0.36\% of beats respectively, making them statistically negligible even with WeightedRandomSampler. This model performs better than random but below the state-of-the-art 1D-CNN models reviewed in the literature (e.g., Guhdar et al. \cite{guhdar2024} at 99.3\%, Kavitha and Shakkeera \cite{kavitha2024} at 99.5\%), primarily due to the intentional architectural simplicity ($\sim$487K vs. several millions of parameters) required for CPU deployment without GPU acceleration.

\textbf{Risk Stratification (deployed thresholds):}
The sigmoid-activated output probability $\hat{y} = \sigma(\text{logit}) \in [0, 1]$ is thresholded as:
\begin{itemize}
  \item \textbf{Low}: $\hat{y} < 0.35$
  \item \textbf{Borderline}: $0.35 \leq \hat{y} < 0.70$
  \item \textbf{Elevated}: $\hat{y} \geq 0.70$
\end{itemize}

\textbf{Discussion:} Test accuracy of 73.4\% and AUROC of 0.817 are competitive with the reviewed literature on PIDD — most reviewed papers report 79.2\%--86.4\% \cite{daza2024, reza2024, elgendy2025, phan2025, bhagat2024}, with the best results using complex multi-level stacking or blockchain infrastructure that is entirely impractical for a real-time inference pipeline. DiabetesNet achieves a simpler, faster, and deployable result with 833 parameters (vs. multi-thousand parameter ensembles). The lower diabetic-class recall (0.56) reflects the class imbalance (54 vs. 100 in the test set) and is consistent across all reviewed literature.

\subsection{ParkinsonNet — Motor Risk Assessment}
% ──────────────────────────────────────────────────────────────────────

ParkinsonNet was trained for 120 epochs on the UCI Parkinson's Dataset (156 training / 39 test samples, stratified split with \texttt{random\_state=42}). The model operates on 22 StandardScaler-normalised voice biomarkers; scaler constants are stored in \texttt{inference/parkinson.py}. For real-time inference, the 22 features are extracted from uploaded WAV files using the pipeline in \texttt{extract\_voice\_features()}, which uses \texttt{librosa.pyin()} (pYIN algorithm \cite{pyin2014}) for fundamental frequency estimation, and custom NumPy implementations for jitter, shimmer, NHR/HNR, RPDE, DFA, D2, and pitch entropy.

\textbf{Risk Stratification (deployed thresholds):}

\textbf{Discussion:} 97.4\% accuracy and 0.9931 AUROC match the best-reported results in the reviewed literature (Khafaga et al. \cite{khafaga2024} 97.4\%, Guatelli et al. \cite{guatelli2024} 96.5\%, Palakayala and Kuppusamy \cite{palakayala2024} 97.6\%). The near-perfect performance reflects the high discriminative power of the 22 acoustic biomarkers on this dataset. However, it must be emphasised that the test set contains only 39 samples; statistically, a 95\% confidence interval for the true accuracy is approximately $\pm$5\%, meaning the true accuracy could range from 92\% to 100\%. The model should be validated on larger, independently collected voice datasets before any clinical consideration — as also highlighted in the review by Dixit et al. \cite{dixit2024} and Islam et al. \cite{islam2024}.

\section{Discussion}
% ──────────────────────────────────────────────────────────────────────

\subsection{Strengths}

\begin{enumerate}
  \item \textbf{Safety by architecture}: The double-pass \ac{llm} pipeline structurally prevents hallucination of risk values — the primary safety concern identified in Gap 3. Unlike Peixoto et al. \cite{peixoto2024} where LLMs generate assessments, here the LLM only interprets PyTorch outputs.
  \item \textbf{Accessibility}: No prior system provides simultaneous multi-disease conversational screening from a single browser session. All three identified gaps (2, 4, 5) regarding data collection, ECG access, and voice analysis are addressed.
  \item \textbf{ParkinsonNet performance}: 97.4\% accuracy and AUROC 0.9931 match the state-of-the-art reviewed literature results on the UCI dataset.
  \item \textbf{Deployability}: The entire system operates on CPU hardware with no GPU requirement, using open-source tools, at zero marginal cost on free-tier cloud hosting.
  \item \textbf{Triage system}: The rule-based three-level triage (routine / recommended check / priority review) provides clinically actionable output even when individual model probabilities are close to decision boundaries.
\end{enumerate}

\subsection{Limitations}

\begin{enumerate}
  \item \textbf{ECGNet overfitting}: The 38.55-percentage-point training-test accuracy gap is a significant limitation. The models reviewed in the literature that achieve 99\%+ accuracy also use near-identical train/test data from MIT-BIH — but the key difference is that our deployment architecture (CPU, single-lead, lightweight model) prioritises accessibility over peak benchmark accuracy.
  \item \textbf{S-class and F-class failure}: ECGNet achieves F1 = 0.06 (S-class) and F1 = 0.04 (F-class), identical to the failure modes documented across the reviewed literature \cite{ayyub2025, kerdoudi2024}. This reflects the fundamental inadequacy of the MIT-BIH dataset for minority-class learning, not an architecture-specific flaw.
  \item \textbf{Demographic specificity}: DiabetesNet is trained exclusively on PIDD (female Pima Indian patients) — the same demographic limitation present in all 15 reviewed diabetes papers that use this dataset.
  \item \textbf{Small Parkinson's test set}: 39-sample test evaluation is insufficient for robust clinical confidence intervals, as noted across 12 of the 16 reviewed Parkinson's papers including \cite{dixit2024, islam2024}.
  \item \textbf{Voice feature approximation}: RPDE, DFA, and D2 are computed using custom NumPy approximations rather than the clinically validated implementations used in the original UCI study \cite{little2008}.
\end{enumerate}
