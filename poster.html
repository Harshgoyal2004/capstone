Introduction

Cardiovascular disease, diabetes mellitus, and Parkinson's disease collectively account for millions of deaths annually. The WHO reports 17.9 million CVD deaths per year, while 500+ million individuals live with type 2 diabetes and 10 million with Parkinson's disease globally.

Despite a large body of academic ML research, no single interactive tool exists that screens a patient for all three diseases in one session. Existing solutions are single-disease, require structured form-based input, and produce outputs interpretable only by clinicians.

Research Gap: 49 reviewed papers each address only one disease domain. None deploy a conversational, multi-disease, hallucination-safe AI screening system.
Motivation
  • Pre-symptomatic screening greatly improves patient outcomes for all three diseases.
  • Existing tools are fragmented: cardiac, metabolic, and motor screening require separate specialist visits.
  • LLM-based tools (e.g., Peixoto et al., 2024) risk hallucinating medical probabilities — posing direct patient safety risks.
  • This project introduces a novel double-pass LLM architecture that prevents hallucination by design: all numerical risk values originate exclusively from PyTorch inference.
Scope of the Project
  • Three disease domains: Cardiac arrhythmia (ECG), Diabetes mellitus (8 biomarkers), Parkinson's disease (voice)
  • File inputs: CSV ECG waveforms, WAV voice recordings
  • Conversational intake for all metabolic biomarkers via Gemini LLM chat
  • Automated triage: Routine → Recommended Check → Priority Review
  • Non-diagnostic: Explicitly presented as a screening tool only
  • CPU-deployable on free-tier cloud (Render)
Methodology

Double-Pass LLM Architecture:

Fig. 1 — Double-Pass LLM Pipeline. The LLM never generates risk numbers; all probabilities originate from PyTorch inference.

Three PyTorch Models:

  • ECGNet — Multi-Scale Attention 1D-CNN, 487K params, trained on MIT-BIH (109,446 beats). Focal Loss (γ=2) addresses severe class imbalance.
  • DiabetesNet — Tabular DNN (8→32→16→1), 833 params, trained on Pima Indians Diabetes Dataset (768 samples).
  • ParkinsonNet — Voice Feature DNN (22→64→32→1), 3,617 params, trained on UCI Parkinson's Dataset (195 recordings, 22 acoustic biomarkers).

Tech Stack: Python 3.10+ · FastAPI · PyTorch ≥2.0 · Streamlit · Google Gemini API · librosa · SciPy

Conclusion
  • First multi-disease conversational AI screening tool addressing 6 identified research gaps.
  • Novel double-pass LLM architecture eliminates hallucination risk — LLM interprets, never generates risk scores.
  • Fully deployable on CPU-only free-tier cloud; requires only a browser.
  • ParkinsonNet achieves 97.4% accuracy / AUROC 0.9931, on par with state-of-the-art literature.
  • Future work: Multi-lead ECG support, multi-ethnic datasets, clinical pilot study, OAuth2 security, real-time audio.
